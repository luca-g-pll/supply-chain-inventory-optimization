# 10 — Test Plan

Tool: `pytest` (+ `hypothesis` for property tests). CI: GitHub Actions (`.github/workflows/ci.yml`) runs `ruff check` and `pytest` on every push.

## 1. Test levels

`pytest` runs **96 tests in about 10 seconds**, all on synthetic data generated by `src/synthetic.py` (Kaggle-shaped:
stores × items × days with trend, weekly and yearly seasonality and Poisson noise), so CI never needs the Kaggle
download.

| Level | What | Where |
|---|---|---|
| Unit | Formulas, metrics, classification, parsers | `test_inventory.py`, `test_metrics.py`, `test_classification.py`, `test_ingest.py` |
| Property / invariant | Simulation physics on random demand (`hypothesis`) | `test_simulation.py` |
| Leakage | Forecasts and features never change when data after the origin changes | `test_forecast.py` |
| Integration | SQL vs. pandas, scenario vs. direct simulation, in-memory run, CLI and exit codes | `test_sql.py`, `test_scenario.py`, `test_pipeline.py`, `test_profile.py` |
| Sample data | Generator is deterministic; holidays, closures, launches, seasons and promotions are present; the samples pass the input contract | `test_sample_data.py` |
| Manual / acceptance | Notebooks top-to-bottom, dashboard pages, upload flow | checklist §3 |

### Simulation invariants (`tests/test_simulation.py`)
| ID | Invariant |
|---|---|
| T-S1 | Stock balance each day: `on_hand_end = on_hand_begin + receipt − sales` |
| T-S2 | `0 ≤ sales ≤ demand` and `on_hand ≥ 0` always |
| T-S3 | `sales + lost = demand` |
| T-S4 | Every order arrives exactly `L` days later |
| T-S5 | Zero demand → fill rate defined as 1, no orders beyond the initial state |
| T-S6 | Huge `s` → fill rate = 1; `s = −∞` with P1 → no orders |
| T-S7 | `calibrate_to_fill_rate` ends within tolerance |
| T-S8 | Deterministic: same inputs → same outputs |
| T-S9 | With backorders: `sales + backordered + lost = demand` and the backlog is served before new demand |
| T-S10 | `backorder_share = 0` gives exactly the lost-sales result |
| T-S11 | `backorder_share > 0` → lost units ≤ lost units of the same series with `share = 0` |
